# The Art of Noticing

**The Art of Noticing** is a short, browser-based visual novel about observation, logic, and psychology. Learn with Dr. Aris, solve a number-sequence puzzle, observe a witness, and search a cluttered room for a hidden key.

## Play

No installation, build step, or server is required:

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Choose dialogue options to continue through the story.

The game loads Tailwind CSS and Google Fonts from their CDNs, so an internet connection is needed for those external resources. The game itself is contained in `index.html` and can be opened locally.

## How to play

- Select a dialogue choice to advance the story and answer the puzzles.
- Click the dialogue box while text is appearing to reveal it immediately.
- In the hidden-object puzzle, click the golden key to find the clue. Clicking other objects affects your logic score.
- Your perception and logic scores are shown during the game and summarized at the end.
- Choose **Play Again** on the end screen to restart.

## Features

- Branching dialogue and character scenes
- A number-sequence logic question
- An observation challenge focused on noticing details
- A randomized hidden-object puzzle
- Perception and logic scoring with a final assessment
